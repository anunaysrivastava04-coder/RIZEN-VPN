Privacy notice
  • Free servers are run by strangers. They can see which sites you connect to, and anything on plain HTTP pages. HTTPS content stays encrypted. Never log in to banking or email through them.
  • Server lists come from Geonode, Proxifly (GitHub / jsDelivr) and ProxyScrape. Those sites see your real IP when the list is fetched.
  • Each server is checked with Cloudflare and Google test pages. One check is made before connecting, directly, to learn your real IP so leaks can be detected. It stays in memory and is cleared when you disconnect.
  • DNS tests contact the provider you pick. Nothing is sent to RIZEN-VPN or any analytics service.
  • Saved on this device only: your settings, the connection state and a short-lived server list.

Before you connect

  • Free servers are public and run by strangers. They can see the sites you visit and anything sent over plain HTTP.
  • RIZEN checks every server, blocks traffic if it fails, and never uses your passwords. It can't make an untrusted server trustworthy.
  • Avoid banking and email logins. Full details are in the Safety tab.
